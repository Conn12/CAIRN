# mcu-3d · STM32 系统结构解剖

把 STM32F103C8T6 的内部结构做成可交互的 3D 剖面，用来学习：

- Cortex-M3 内核与 ICode / DCode / 系统总线
- 总线矩阵的 4 主 4 从结构
- Flash / SRAM 的地址映射
- AHB2APB 桥、APB1（36MHz）与 APB2（72MHz）的外设分工
- DMA 搬运与 RCC 时钟树

## 运行

双击 `serve.bat`，浏览器会自动打开：

```
http://127.0.0.1:8777/tools/mcu-3d/
```

必须通过本地 HTTP 服务打开，不能直接双击 `index.html`（ES Module 不支持 `file://`）。
关闭那个最小化的服务窗口即可停止。

## 操作

- 拖动旋转，滚轮缩放；点击任意模块看右侧说明
- 顶部章节 01–06；键盘 `←` / `→` 切换；地址栏 `#01`–`#06` 可直达
- 底部数据流：跟随章节 / 取指 / 取数 / 外设 / DMA / 时钟
- 左侧：标签、描边、Bloom、自动旋转、重置视角
- 第 04 章右侧有外设索引，可直接点选小外设

## 依赖

Three.js 直接复用 `..\..\site\node_modules\three`，不复制、不引 CDN。
没有构建步骤，改完源码刷新浏览器即可。

## 型号说明

STM32F103C8T6：64KB Flash、20KB SRAM、DMA1 7 通道、无 FSMC。
场景中的 FSMC 与 DMA2 属于 F103 系列结构，按虚体保留并标注“部分型号”。

## 注意

`serve.bat` 必须保持 CRLF 换行（LF 会让 cmd 解析错位）。
