# CAIRN

> 一路走，一路堆石头。

一个人的学习日志站。

- 计划书：[PLAN.md](PLAN.md)
- 思维导图：[mindmap.html](mindmap.html)（浏览器打开）
- 项目规则：[CLAUDE.md](CLAUDE.md)

## 本地开发

```bash
cd site
npm install     # 首次
npm run dev     # http://localhost:4321
npm run build   # 输出到 site/dist/
```

文章写在 `content/posts/`，文件名 `YYYY-MM-DD-slug.md`，站里会自动索引。
