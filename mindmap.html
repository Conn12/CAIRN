一路走，一路堆石头

定位

  • 一个人的学习日志
  • 第一用户是我自己
  • 顺便给别人看

内容

  • 学习记录（最高频）
  • 项目复盘
  • 工具说明
  • 3D / 实验（低频）

节奏

  • 每周 1–2 篇
  • 10 分钟能发一篇
  • 丑着发，别打磨

成功标准

  • 30 天：6 篇
  • 90 天：还在更新
  • 180 天：有自用工具
  • 不看访问量
CAIRN
一个人的石头堆
每走一步，留一个记号

技术

  • Astro + Markdown
  • 静态托管
  • 零后端 / 零登录
  • 不用境外 CDN

分期

  • Phase 0（3 天）：能跑能发
  • Phase 1（1 月）：攒 6 篇
  • Phase 2（2–3 月）：加工具
  • Phase 3：按需

红线

  • 新点子先是文章
  • 站是索引不是宿主
  • 不加登录 / 数据库
  • 80 篇前不分类

风险与对策

  • 改样式上瘾 → 限死 3 天
  • 断更 → 降低单篇门槛
  • 功能膨胀 → 红线机制
  • 国内打不开 → 资源自托管
