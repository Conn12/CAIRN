# EC-S100 手表演示台 · 单模型交接

## 概览

- 模型：EC-S100 智能手表演示台
- 路由：`/models/ec-s100-watch/`
- 形态：**不是成品手表**，而是“主控板 + 扩展板 + 插在扩展板上的 240×280 屏幕模块”
- 目标：按代码还原界面、传感器数据和 OTA 链路，用来后续学习
- 源码工程：`D:\32\_LIXIN\_OTA\源代码及工具\ec_s100_watch_V2.6_T3191`
- 当前版本：`v0.17.0`（17 模块化底板）

## 硬件底图

主控 **STM32F411CEU6**（UFQFPN48），FreeRTOS + LVGL，240×280 屏。

| 类别 | 器件 / 引脚 |
| --- | --- |
| 主控 | STM32F411CEU6 |
| 显示 | ST7789，240×280，SPI1（PA4 CS / PA5 CLK / PA6 DC / PA7 MOSI / PB10 RST），背光 PA1 |
| 触摸 | CST816T，I2C3（PA8 SCL / PB4 SDA），中断 PB2，复位 PA15 |
| 心率 | EM7028，I2C1，中断 PA3 |
| 温湿度 | AHT21，I2C1 |
| 气压 | SPL06，I2C1 |
| 运动/计步 | MPU6050，I2C1，中断 PB5 |
| 磁力计 | LIS2MDL，I2C1 |
| 充电管理 | HP4570，I2C1；电池 ADC PB0 |
| 外部 Flash | W25Q64 / W25Q128（代码两处命名不一致），SPI2 |
| 语音 | WT588，PB8 信号 / PB9 状态 |
| 振动马达 | PB3 MOTOR_EN |
| 按键 | PA0 USER_KEY3、PB1 USER_KEY1 |
| 蓝牙 | 外部模块，USART1（PA9 TX / PA10 RX，代码里叫 BT_UART） |
| 其他 | 环境光 ADC PA2、LED PC13、RTC 32.768k、IWDG |

## 软件功能

- LVGL 22 个页面：欢迎、3 个表盘、top_lap、menu_1/2/3、心率、消息、NFC、二维码、电子围栏、天气、恶劣天气预警、设置、系统更新、版本检测、OTA 下载、OTA 升级、错误页。
- 传感器：AHT21 温湿度、EM7028 心率、SPL06 气压、MPU6050 计步、LIS2MDL 磁力计；电池监测、环境光。
- OTA 链路：蓝牙模块从 USART1 收到 `0x11 0x22 0x33` → 屏幕确认 → YMODEM 接收 → 写 W25Q 外部 Flash → 写 App 标志区 `0x08008000` → 软复位 → Bootloader 搬运到 `0x0800C000`。
- 其他：HP4570 充电管理、WT588 语音、振动马达、按键、RTC、看门狗、低功耗。
- 注意：NFC、GPS/电子围栏、二维码组网在代码里只有 UI，没有对应硬件驱动；数据来自蓝牙/手机。

## 当前实现（v0.17.0）

- 3D：ZET6 风格模块化底板：32×22 底板 + STM32F411 核心板 + 十六块可插拔模块（屏幕、触摸、5 个传感器、存储、充电、电池、蓝牙、语音、马达、按键、LED、光敏）。
- 每块模块是独立 PCB，带 2.54mm 排针、模块丝印和引脚标签；右侧“模块”页有模块列表、引脚表和插拔按钮。
- 屏幕镜像：240×280 HTML 镜像，10 个页面（表盘、菜单、心率、消息、设置、OTA、NFC、二维码、围栏、天气）。
- 传感器模拟：温度、湿度、气压、心率、步数、电量六个滑块，屏幕和 3D 屏同步。
- 器件讲解：点击 3D 器件或标签，右侧「器件」页显示是什么 / 做什么 / 怎么用。
- OTA：命令 → YMODEM → W25Q → 标志区 → 软复位 → 版本 V2.6 → V2.7，带进度和日志。
- 插拔：每块模块可单独插入/拔出，左侧“全部拔出/全部插入”批量操作；屏幕、传感器、OTA 与模块状态联动。
- 六章：硬件组合 / 主控板 / 扩展板 / 屏幕与交互 / OTA 升级 / 传感器。

## 已知缺口

1. **页面没有补齐**：当前 10 个，目标 22 个；缺欢迎、3 个表盘、top_lap、menu_1/2/3、系统更新/版本检测、OTA 检查、恶劣天气预警、错误页等。
2. **UI 还原度**：目前是 HTML 重建，颜色/字体/图标按代码推断，不是逐像素还原。
3. **实物细节**：没有主板/扩展板/屏幕照片和尺寸，器件位置是合理近似；表壳/连接器/排线可以继续精修。
4. **蓝牙模块型号**：代码只写 `BT_UART`，没有模块名；W25Q64 / W25Q128 两处命名不一致。
5. **NFC/GPS**：只有 UI，没有硬件驱动；模型里按 UI 演示处理。
6. **共享舞台**：和 STM32 页各自维护 HUD，后续抽 `ModelStage`。
7. **移动端**：窄屏面板和屏幕镜像偏挤。

## 接手提示

- 先读 `content.js` 的器件和章节，再看 `main.js` 的场景装配、屏幕镜像和 OTA 状态机。
- 屏幕是 240×280，HTML 镜像就是代码尺寸；3D 屏是同一份状态的 canvas 纹理。
- 插拔会禁用传感器和 OTA；改逻辑时同时处理 `state.plugged`。
- 改完必须 `npm run build`；用无头浏览器检查 `/models/` 和 `/models/ec-s100-watch/`。
- OTA 计时器在后台标签会被浏览器节流，测试时多等一会，或在可见窗口里看。
