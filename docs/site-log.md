# CAIRN · 站点总日志

> 这份文件是交接入口。新会话接手时，按“接手必读顺序”往下读。

## 一句话

一个人的学习日志站。Astro + Markdown，手写 CSS，零后端、零运行时，静态托管。

## 当前状态（v0.17.1）

- 站点：Astro 7 + Three.js 0.187；手写 CSS，不引 UI 框架。
- 四个模块：文章、分享、学习、物理模型。
- 本地开发：

  ```bash
  cd site
  npm install     # 首次
  npm run dev     # http://localhost:4321
  npm run build   # 输出到 site/dist/
  ```

- 上线：尚未配置托管。PLAN 的目标是 Cloudflare Pages，备选阿里云 OSS + CDN。
- 备份：私有远程仓库已建：`https://github.com/Conn12/CAIRN.git`。不自动 push，只在明确指示时推送。
- 当前版本：`v0.14.1`（记录首次云端备份）。

## 交接提示

- 每个版本：提交 + 打标签 + 更新 `version-log` + 更新对应模块日志；大改动再更新本文件。
- 不自动 push；远程仓库等明确指示。
- 临时文件进 `.local\tmp\`，用完即删。
- `.local\` 是缓存、`.claude\` 是本机配置，都不算备份。
- 交接或暂停前：把当前状态、未完成项、下一步写进对应日志，再结束会话。
- 跨 AI 交接：把 `docs\handoff.md` 顶部的启动提示复制给接手 AI；停止时按 `docs\handoff-return-template.md` 写交回记录。
