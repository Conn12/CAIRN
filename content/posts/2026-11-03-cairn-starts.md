## 为什么是 CAIRN

Cairn 是路边的石堆：走过的人一块一块往上加，给后来的人指路。这个站也是一样——不追求单篇写得多好，只要求一直在加。

> 单件可以粗糙，整体在增值。

## 这里会有什么

- 学习记录：今天搞懂了什么，随手写下来
- 项目复盘：做完了就写，翻车也写
- 工具说明：工具放 GitHub，这儿只放一篇文章和链接
- 实验：3D、可视化这类低频但好玩的东西

## 一条命令发一篇文章

```bash
npm run dev
```

草稿放在 `content/drafts/`，写完挪进 `content/posts/`，文件名是 `YYYY-MM-DD-slug.md`。
